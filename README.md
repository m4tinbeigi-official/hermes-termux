# 🚀 Mr Hermes & 9Router Stack for Android Termux

نصب و راه‌اندازی تمام‌خودکار و تک‌دستوری کل اکوسیستم هوش مصنوعی روی ترموکس اندروید:
**9Router** (درگاه مدل‌ها) + **Hermes Agent** (عامل هوشمند) + **Mr Hermes WebUI** (رابط وب فارسی و راست‌چین).

مجهز به نگهبان خودکار (Self-Healing Watchdog)، اجرای خودکار هنگام روشن شدن گوشی (Termux:Boot)، ویجت‌های تک‌لمسی صفحه اصلی گوشی و باز شدن خودکار مرورگر.

---

## ⚡️ نصب سریع با یک دستور در ترموکس (One-Command Setup)

اگر برای اولین بار است که ترموکس را روی گوشی باز می‌کنید، فقط کافیست این یک خط کد را داخل ترموکس کپی و اجرا کنید:

```bash
pkg update -y && pkg install -y curl && curl -fsSL https://raw.githubusercontent.com/m4tinbeigi-official/hermes-termux/main/install.sh | bash
```

> **نکته:** در صورتی که `curl` از قبل روی ترموکس شما نصب است، دستور کوتاه زیر کافیست:
> ```bash
> curl -fsSL https://raw.githubusercontent.com/m4tinbeigi-official/hermes-termux/main/install.sh | bash
> ```

## 🌟 قابلیت‌های خودکار ارتقایافته (Pro Features)

1. **باز شدن خودکار مرورگر (Zero-Click Browser Launch):** بلافاصله پس از اتمام نصب، مرورگر پیش‌فرض گوشی با آدرس `http://localhost:8787` به طور خودکار باز می‌شود.
2. **نگهبان خودکار و خودترمیمی (Self-Healing Watchdog):** در صورتی که مدیریت باتری یا رم اندروید (LMK) سرویس‌ها را ببندد، نگهبان هوشمند در پس‌زمینه ظرف ۳۰ ثانیه مجدداً سرویس‌ها را بالا می‌آورد.
3. **روشن شدن هم‌گام با گوشی (Termux:Boot):** در صورت نصب بودن Termux:Boot، با هر بار ری‌استارت شدن گوشی، کل استک بدون نیاز به باز کردن ترموکس در بک‌گراند اجرا می‌شود.
4. **ویجت‌های لمسی روی صفحه اصلی (Termux:Widget):** شورت‌کات‌های آماده داخل `~/.shortcuts/` ساخته می‌شوند تا بتوانید دکمه‌های اجرای سریع و باز کردن وب یوآی را مستقیماً به عنوان ویجت روی صفحه گوشی بگذارید.
5. **نوتیفیکیشن بومی اندروید:** ارسال اعلان تایید لایو بودن سرویس‌ها به استاتوس بار گوشی.
6. **دستیار عیب‌یابی و آپدیت تک‌کلیکه (`hermes-doctor` و `hermes-update`):** بررسی سلامت رم، فضا و اتصالات یا آپدیت کل اجزا با یک دستور.

## 🌐 نحوه دسترسی و استفاده

پس از پایان نصب خودکار، همه سرویس‌ها در پس‌زمینه شروع به کار می‌کنند:

1. مرورگر گوشی (Chrome یا Firefox) را باز کنید.
2. به نشانی زیر بروید:
   **`http://localhost:8787`**
3. پنل کاربری مستر هرمس با پشتیبانی کامل از زبان فارسی و چینش راست‌چین لود می‌شود.

## 📱 دستورات سریع در محیط ترموکس

پس از نصب، شورت‌کات‌های زیر مستقیماً در شل ترموکس در دسترس هستند:

- `hermes-web`: استارت سرویس‌ها، اجرای نگهبان پس‌زمینه و باز کردن مستقیم مرورگر اندروید
- `hermes-start`: اجرای هر دو سرویس (9Router و WebUI) به همراه Watchdog
- `hermes-stop`: متوقف‌سازی کامل تمام سرویس‌ها و نگهبان
- `hermes-status`: بررسی وضعیت فعال بودن پورت‌های ۸۷۸۷ و ۲۰۱۲۸ و میزان رم مصرفی
- `hermes-doctor`: دیاگ کامل وضعیت سخت‌افزار، حافظه و اتصالات
- `hermes-update`: به‌روزرسانی تک‌کلیکه تمام مخازن، وب یوآی و پکیج‌های پایتون و npm
- `hermes-cli`: ورود به خط فرمان اختصاصی هرمس ایجنت برای کدنویسی در ترمینال

## ⚙️ معماری فنی (Technical Architecture)

```
        Android Device (Termux Userland)
                      │
           ┌──────────▼──────────┐
           │   proot-distro      │
           │  (Ubuntu 22.04 LTS) │
           └──────────┬──────────┘
                      │
      ┌───────────────┼───────────────┐
      ▼               ▼               ▼
 ┌──────────┐   ┌───────────┐   ┌───────────┐
 │ 9Router  │   │  Hermes   │   │ Mr Hermes │
 │ Gateway  │◀──┤   Agent   │◀──┤   WebUI   │
 │  :20128  │   │    CLI    │   │   :8787   │
 └──────────┘   └───────────┘   └───────────┘
      │               ▲               ▲
      └───────────────┴───────────────┘
           Local Shared Loopback
```

- **پایداری پردازنده:** فعال‌سازی خودکار `termux-wake-lock` برای جلوگیری از توقف پردازش‌ها توسط مدیریت باتری اندروید.
- **شبکه مشترک:** دسترسی مستقیم به پورت‌های `8787` و `20128` از داخل سیستم عامل اندروید بدون نیاز به روت یا کانفیگ پیچیده.
- **ایزوله‌سازی:** استفاده از لایه سبک `proot-distro` برای تضمین سازگاری کامل باینری‌های لینوکس و کتابخانه‌های پایتون.
