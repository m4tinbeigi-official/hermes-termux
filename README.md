# 🚀 Mr Hermes & 9Router Stack for Android Termux

نصب و راه‌اندازی تمام‌خودکار و تک‌دستوری کل اکوسیستم هوش مصنوعی روی ترموکس اندروید:
**9Router** (درگاه مدل‌ها) + **Hermes Agent** (عامل هوشمند) + **Mr Hermes WebUI** (رابط وب فارسی و راست‌چین).

---

## ⚡️ نصب سریع با یک دستور در ترموکس (One-Command Setup)

اگر برای اولین بار است که ترموکس را روی گوشی باز می‌کنید، فقط کافیست این یک خط کد را داخل ترموکس کپی و اجرا کنید:

```bash
pkg update -y && pkg install -y curl && curl -fsSL https://raw.githubusercontent.com/m4tinbeigi-official/hermes-termux/main/install.sh | bash
```

> **نکته:** در صورتی که `curl` از قبل روی ترموکس شما نصب است، دستور کوتاه زیر کافیست:
> ```bash
> curl -fsSL https://raw.githubusercontent.com/m4tinbeigi-official/hermes-termux/main/install.sh | bash
> ```

---

## 🌐 نحوه دسترسی و استفاده

پس از پایان نصب خودکار، همه سرویس‌ها در پس‌زمینه شروع به کار می‌کنند:

1. مرورگر گوشی (Chrome یا Firefox) را باز کنید.
2. به نشانی زیر بروید:
   **`http://localhost:8787`**
3. پنل کاربری مستر هرمس با پشتیبانی کامل از زبان فارسی و چینش راست‌چین لود می‌شود.

---

## 🛠 اجزای نصب‌شده و پورت‌ها

| مؤلفه | نقش در سیستم | آدرس / پورت |
| :--- | :--- | :--- |
| **Mr Hermes WebUI** | پنل چت تحت وب، مدیریت فایل‌ها و ابزارها | `http://localhost:8787` |
| **9Router** | گیت‌وی سبک هوش مصنوعی و مسیریابی مدل‌ها | `http://localhost:20128` |
| **Hermes Agent** | هسته عامل خودکار خط فرمان و مهارت‌ها | ترمینال (`hermes-cli`) |

---

## 📱 دستورات سریع در محیط ترموکس

پس از نصب، شورت‌کات‌های زیر مستقیماً در شل ترموکس در دسترس هستند:

- `hermes-start`: اجرای هر دو سرویس (9Router و WebUI) در پس‌زمینه
- `hermes-stop`: متوقف‌سازی تمام سرویس‌ها
- `hermes-status`: بررسی وضعیت فعال بودن پورت‌های ۸۷۸۷ و ۲۰۱۲۸
- `hermes-web`: استارت سرویس‌ها و باز کردن خودکار آدرس در مرورگر گوشی
- `hermes-cli`: ورود به خط فرمان اختصاصی هرمس ایجنت

## ⚙️ معماری فنی (Technical Architecture)

```
        Android Device (Termux Userland)
                      │
           ┌──────────▼──────────┐
           │   proot-distro      │
           │  (Ubuntu 22.04 LTS) │
           └──────────┬──────────┘
                      │
      ┌───────────────┼───────────────┐
      ▼               ▼               ▼
 ┌──────────┐   ┌───────────┐   ┌───────────┐
 │ 9Router  │   │  Hermes   │   │ Mr Hermes │
 │ Gateway  │◀──┤   Agent   │◀──┤   WebUI   │
 │  :20128  │   │    CLI    │   │   :8787   │
 └──────────┘   └───────────┘   └───────────┘
      │                               ▲
      └───────────────────────────────┘
           Local Shared Loopback
```

- **پایداری پردازنده:** فعال‌سازی خودکار `termux-wake-lock` برای جلوگیری از توقف پردازش‌ها توسط مدیریت باتری اندروید.
- **شبکه مشترک:** دسترسی مستقیم به پورت‌های `8787` و `20128` از داخل سیستم عامل اندروید بدون نیاز به روت یا کانفیگ پیچیده.
- **ایزوله‌سازی:** استفاده از لایه سبک `proot-distro` برای تضمین سازگاری کامل باینری‌های لینوکس و کتابخانه‌های پایتون.
