# 🚀 Mr Hermes & 9Router Stack for Android Termux (v3 Pro)

نصب و راه‌اندازی تمام‌خودکار، فوق‌پیشرفته و تک‌دستوری کل اکوسیستم هوش مصنوعی روی ترموکس اندروید:  
**9Router** (درگاه مدل‌ها و پراکسی) + **Hermes Agent** (هسته عامل خودکار) + **Mr Hermes WebUI** (رابط کاربری مدرن، فارسی و راست‌چین).

مجهز به منوی تعاملی سایبرپانک، تانل ابری امن برای دسترسی از لپ‌تاپ با QR Code، نگهبان خودکار (Self-Healing Watchdog)، اجرای خودکار هنگام بوت گوشی (Termux:Boot) و ویجت‌های صفحه اصلی.

---

## ⚡️ نصب فوق‌سریع با یک دستور در ترموکس (One-Command Setup)

اگر برای اولین بار است که ترموکس را روی گوشی باز می‌کنید، فقط کافیست این یک خط کد را داخل ترموکس کپی و اجرا کنید:

```bash
pkg update -y && pkg install -y curl && curl -fsSL https://raw.githubusercontent.com/m4tinbeigi-official/hermes-termux/main/install.sh | bash
```

> **نکته:** در صورتی که `curl` از قبل روی ترموکس شما نصب است، دستور کوتاه زیر کافیست:
> ```bash
> curl -fsSL https://raw.githubusercontent.com/m4tinbeigi-official/hermes-termux/main/install.sh | bash
> ```

## 🌟 قابلیت‌های طلایی نسخه جدید (v3 Pro Engine)

1. **داشبورد کنترل تعاملی سایبرپانک (`hermes` یا `hermes-menu`):**  
   با نوشتن کلمه `hermes` در ترمینال، یک منوی تعاملی و زیبا باز می‌شود که وضعیت زنده پورت‌ها را نشان داده و با زدن اعداد ۱ تا ۷ تمام ابزارها در اختیارتان قرار می‌گیرد.
2. **اتصال ریموت ابری و کیوآرکد (`hermes-share`):**  
   می‌خواهید با لپ‌تاپ، تبلت یا سیستم دیگری از وب‌یوآی گوشی‌تان استفاده کنید؟ دستور `hermes-share` یک تانل امن HTTPS بر بستر کلودفلر می‌سازد و یک QR Code مستقیم در ترمینال رسم می‌کند تا با دوربین لپ‌تاپ اسکن کرده و فوری وصل شوید.
3. **باز شدن خودکار مرورگر (Zero-Click Launch):**  
   بلافاصله پس از اتمام نصب، مرورگر پیش‌فرض گوشی با آدرس `http://localhost:8787` به طور خودکار باز می‌شود.
4. **نگهبان خودکار و خودترمیمی (Self-Healing Watchdog):**  
   در صورتی که مدیریت باتری یا رم اندروید (LMK) سرویس‌ها را متوقف کند، دیمن نگهبان در پس‌زمینه هر ۳۰ ثانیه سوکت‌ها را بررسی و سرویس‌های خوابیده را بیدار می‌کند.
5. **روشن شدن هم‌گام با گوشی (Termux:Boot):**  
   در صورت نصب بودن برنامه Termux:Boot، با هر بار ری‌بوت یا روشن شدن گوشی، کل استک بدون نیاز به باز کردن ترموکس در بک‌گراند اجرا می‌شود.
6. **ویجت‌های لمسی روی صفحه اصلی (Termux:Widget):**  
   شورت‌کات‌های آماده داخل `~/.shortcuts/` ایجاد شده تا بتوانید دکمه‌های اجرای سریع، تانل و توقف را مستقیماً به عنوان ویجت روی صفحه اصلی گوشی قرار دهید.
7. **پیش‌تنظیم کامبوها در 9Router:**  
   جدول کامبوها و کلید ادمین در دیتابیس داخلی SQLite باینری با نام `MrHermes` و هدایت هوشمند مدل‌ها از پیش ست شده است.

## 🌐 نحوه دسترسی و استفاده

پس از پایان نصب خودکار، همه سرویس‌ها در پس‌زمینه شروع به کار می‌کنند:

1. مرورگر گوشی (Chrome یا Firefox) را باز کنید.
2. به نشانی زیر بروید:  
   **`http://localhost:8787`**
3. پنل کاربری مستر هرمس با پشتیبانی کامل از زبان فارسی و چینش راست‌چین لود می‌شود.

## 🛠 اجزای نصب‌شده و پورت‌ها

| مؤلفه | نقش در سیستم | آدرس / پورت |
| :--- | :--- | :--- |
| **Mr Hermes WebUI** | پنل چت تحت وب، مدیریت فایل‌ها و ابزارها | `http://localhost:8787` |
| **9Router** | گیت‌وی هوش مصنوعی و مسیریابی مدل‌ها | `http://localhost:20128` |
| **Hermes Agent** | هسته عامل خودکار خط فرمان و مهارت‌ها | ترمینال (`hermes-cli`) |
| **Cloudflare Tunnel** | درگاه دسترسی ریموت با آدرس امن جهانی | `hermes-share` |

## 📱 دستورات سریع در محیط ترموکس

پس از نصب، شورت‌کات‌های زیر مستقیماً در شل ترموکس در دسترس هستند:

- `hermes`: باز کردن کنترل پنل تعاملی ترمینال
- `hermes-web`: استارت سرویس‌ها، اجرای نگهبان و باز کردن مستقیم مرورگر اندروید
- `hermes-share`: ساخت تانل امن کلودفلر و نمایش QR Code برای باز کردن در لپ‌تاپ
- `hermes-start`: اجرای هر دو سرویس (9Router و WebUI) به همراه Watchdog
- `hermes-stop`: متوقف‌سازی کامل تمام سرویس‌ها، تانل و نگهبان
- `hermes-status`: بررسی وضعیت فعال بودن پورت‌های ۸۷۸۷ و ۲۰۱۲۸ و رم مصرفی
- `hermes-doctor`: دیاگ کامل وضعیت سخت‌افزار، حافظه و اتصالات
- `hermes-update`: به‌روزرسانی تک‌کلیکه تمام مخازن، وب یوآی و پکیج‌ها
- `hermes-cli`: ورود به خط فرمان اختصاصی هرمس ایجنت برای کدنویسی

## ⚙️ معماری فنی (Technical Architecture)

```
        Android Device (Termux Userland)
                      │
           ┌──────────▼──────────┐
           │   proot-distro      │
           │  (Ubuntu 22.04 LTS) │
           └──────────┬──────────┘
                      │
      ┌───────────────┼───────────────┐
      ▼               ▼               ▼
 ┌──────────┐   ┌───────────┐   ┌───────────┐
 │ 9Router  │   │  Hermes   │   │ Mr Hermes │
 │ Gateway  │◀──┤   Agent   │◀──┤   WebUI   │
 │  :20128  │   │    CLI    │   │   :8787   │
 └──────────┘   └───────────┘   └───────────┘
      │               ▲               ▲
      └───────────────┴───────────────┘
                      │
             ┌────────▼────────┐
             │ Cloudflare Host │ ──▶ Remote Laptop / PC Access
             │  (trycloudflare)│
             └─────────────────┘
```

- **پایداری پردازنده:** فعال‌سازی خودکار `termux-wake-lock` برای جلوگیری از توقف پردازش‌ها توسط مدیریت باتری اندروید.
- **شبکه مشترک:** دسترسی مستقیم به پورت‌های `8787` و `20128` از داخل سیستم عامل اندروید بدون نیاز به روت یا کانفیگ پیچیده.
- **ایزوله‌سازی:** استفاده از لایه سبک `proot-distro` برای تضمین سازگاری کامل باینری‌های لینوکس و کتابخانه‌های پایتون.
